# Άτλας πρόσβασης

Πόσο καλύπτεται κάθε νομός και κάθε ειδικότητα στον κατάλογο ηλεκτρονικών ραντεβού του
Υπουργείου Υγείας (finddoctors.gov.gr / e-ραντεβού): πόσα σημεία κλείνουν ραντεβού, ανά
100.000 κατοίκους, πόσο μακριά από την έδρα του νομού και πόσο νωρίς υπάρχει ελεύθερο ραντεβού.

Live: https://atlas.haroldpoi.dev

## Δεδομένα

`static/atlas.json` ξαναγράφεται κάθε εβδομάδα από μια πλήρη σάρωση του καταλόγου. Η σάρωση
τρέχει ιδιωτικά, γιατί χρειάζεται συνεδρία TaxisNet. Σε αυτό το repo μπαίνει μόνο το αρχείο που
διαβάζει η σελίδα:

- αθροίσματα ανά νομό × ειδικότητα και φορέα, ημερομηνίες πρώτου ελεύθερου ραντεβού, αποστάσεις·
- ονόματα και διευθύνσεις **μόνο δημόσιων μονάδων** (νοσοκομεία ΕΣΥ, κέντρα υγείας / ΠΦΥ)·
- ιδιώτες και συμβεβλημένοι με τον ΕΟΠΥΥ ιατροί χωρίς όνομα και διεύθυνση, στο κέντρο της πόλης
  τους, με αναγνωριστικό που δεν οδηγεί πίσω στο πρόσωπο.

Οι ημερομηνίες είναι στιγμιότυπα της ημέρας σάρωσης, όχι σημερινή διαθεσιμότητα.

Ο κώδικας είναι MIT. Τα δεδομένα προέρχονται από τον δημόσιο κατάλογο του Υπουργείου Υγείας.
Τα όρια νομών (`static/prefectures.geojson`) είναι οι 51 παλιοί νομοί. Πληθυσμός: ΕΛΣΤΑΤ,
απογραφή 2021.

## Ανάπτυξη

```sh
bun install
bun run dev      # http://localhost:5173
bun run test
bun run build    # static site in build/
```

Κάθε push στο `main` χτίζεται και ανεβαίνει στο GitHub Pages (`.github/workflows/deploy.yml`).
